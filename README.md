# Inkwell — a quiet place to write

A personal, local-first journaling app designed for your phone. No accounts, no cloud, no AI — your words never leave your device.

## Features

- **Daily writing** with titles, moods, tags, and a backdated calendar
- **Autosave** — you can never lose an entry mid-thought
- **Search & filters** across everything you've written
- **Streaks & insights** — 14-day activity bars, mood map, monthly calendar
- **PIN lock** for privacy
- **Dark / light / auto themes** and adjustable writing size
- **Export & import** (JSON backup + Markdown for keeping forever)
- **Installable PWA** — add it to your home screen and use it offline

## Run it

```bash
npm install
npm run dev        # develop
npm run build      # production build -> dist/
npm run preview    # serve the production build locally
```

## Your data

Everything is stored in your browser's local storage on your device. Use **Settings → Export** regularly to keep a backup.
